3.5 Contracts (Interfaces)

IGenricReposatory<TEntity, Tkey>

CRUD operations + specification-based queries. Methods: Add, Update, Delete, GetAsync (by id or spec), GetAllAsync, CountAsync.

ISpecification<T>

Query criteria: Criteria (WHERE), IncludesExpressions (eager loading), OrderBy, OrderByDescending, Skip, Take, IsPaginated.

IUnitOfWork

SaveChangesAsync + GetReposatory<TEntity, Tkey>() for repository access.

IBasketReposatory

Redis-backed: GetAsync(id), UpdateAsync(basket, timeToLive?), DeleteAsync(id).

IDbinitializer

InitilizeAsync() - seeds database: Admin role, admin user, delivery methods, brands, types, products.

3.6 Global Exception Handling

4.2 Implementations

ProductService

Uses IUnitOfWork + IMapper. Builds ProductWithBrandAndTypeSpecifications for queries, maps results to DTOs.

BasketService

Uses IBasketReposatory + IMapper. Maps between CustomerBasket and BasketDto.

OrderService

Uses IUnitOfWork + IMapper + IBasketReposatory. Validates basket, creates Order with OrderItems, clears basket, returns mapped OrderDto.

AuthService

Uses UserManager<AppUser>, SignInManager<AppUser>, IMapper, IConfiguration (for JWT). Register: validates, creates user. Login: validates credentials, generates JWT. GetCurrentUser: returns user DTO with DisplayName and role.

UserService

Uses UserManager<AppUser>, RoleManager<IdentityRole>. Admin operations: list users (includes roles), get by ID, assign role, remove role, toggle lockout, delete user.

ServiceManager

Lazy-initializes ProductService, BasketService, OrderService (IUnitOfWork + IBasketReposatory + IMapper), AuthService (UserManager + SignInManager + IMapper + IConfiguration), UserService (UserManager + RoleManager).

4.3 Specifications

BaseSpecification<T> (abstract)

Criteria, IncludesExpressions, OrderBy/Descending, ApplyPagination(pageSize, pageIndex).

ProductWithBrandAndTypeSpecifications

Two constructors: (int id) for single product, (ProductQueryParameter) for filtered list with sorting + pagination. Includes ProductBrand and ProductType. Filtering: BrandId, TypeId, Search (name contains). Sorting: NameAsc/Desc, PriceAsc/Desc.

ProductCountSpecefications

Same filtering criteria, no includes/sorting/pagination - used for COUNT.

OrderWithItemsAndDeliverySpecification

Includes Order.Items and Order.DeliveryMethod. Two constructors: (int id, string email) and (string email).

4.4 AutoMapper Profiles

ProductProfile

Product -> ProductsRespone: BrandName from ProductBrand.Name, TyepeName from ProductType.Name, PictureUrl resolved via PictureUrlResolver (prepends BaseUrl from config).

BasketProfile

Bidirectional: CustomerBasket <-> BasketDto, BasketItem <-> BasketItemDto.

OrderProfile

Order -> OrderDto (DeliveryMethod, Items, ShippingAddress mapped), OrderItem -> OrderItemDto, DeliveryMethod -> DeliveryMethodDto.

5. Infrastructure Layer

5.1 Presistance (Data Access)

StoreDbContext

EF Core DbContext extending IdentityDbContext<AppUser>. DbSets: Products, ProductBrands, ProductTypes, Orders, OrderItems, DeliveryMethods. Uses ApplyConfigurationsFromAssembly.

Entity Configurations

ProductConfiguration: Product->ProductBrand (FK BrandId), Product->ProductType (FK TypeId), Price decimal(10,3).

OrderConfiguration: OwnsOne(o => o.ShippingAddress), HasOne(o => o.DeliveryMethod).WithMany(), HasMany(o => o.Items).WithOne(), Status converted to string, PaymentIntentId optional.

OrderItemConfiguration: OwnsOne(i => i.ProductItem), Price decimal(10,3).

DeliveryMethodConfiguration: Price decimal(10,3).

GenericRepostatory<TEntity, Tkey>

Implements IGenricReposatory using StoreDbContext. Specification-based queries via SpecificationsEvaluator.

SpecificationsEvaluator

Static utility: applies .Where() -> .Include() (aggregate) -> .OrderBy()/.OrderByDescending() -> .Skip().Take().

UnitofWork

Dictionary-based repository cache. GetReposatory creates/caches one GenericRepostatory per entity type.

BasketReposatory

Redis via StackExchange.Redis. Serializes CustomerBasket to JSON. Default TTL: 30 days.

Dbinitializer

Seeds: Admin role + admin@ecommerce.com / Admin@123 via UserManager/RoleManager, 4 DeliveryMethods (UPS1-3, FedEx, DHL), brands.json, types.json, products.json.

7. API Endpoints

Public Endpoints

GET /api/product

Get all products (paginated, filtered, sorted). Query params: BrandId, Typeid, options, Search, PageIndex, PageSize.

Response: PagenatedRespones<ProductsRespone> with pageIndex, pageSize, Count, data[].

GET /api/product/{id}

Get single product by ID.

Response: ProductsRespone | 404 if not found.

GET /api/product/brands

Get all product brands.

Response: BrandResponse[].

GET /api/product/types

Get all product types.

Response: TypeResponse[].

GET /Baskets?id=

Get basket by ID.

Response: BasketDto | 404 if not found.

POST /Baskets

Create or update basket (upsert). Body: BasketDto.

Response: Updated BasketDto.

DELETE /Baskets/{id}

Delete basket by ID.

Response: 204 No Content.

Auth Endpoints

POST /api/account/register

Register a new user. Body: RegisterDto (DisplayName, Email, Password, PhoneNumber?).

Response: AuthResponseDto (DisplayName, Email, Token, Roles) | 400 validation.

POST /api/account/login

Login with email + password. Body: LoginDto (Email, Password).

Response: AuthResponseDto | 401 Unauthorized.

GET /api/account/currentUser

Get currently authenticated user. Requires JWT Bearer token.

Response: UserDto (Id, DisplayName, Email, PhoneNumber, IsLockedOut, Roles).

Order Endpoints (Authenticated)

POST /api/orders

Create order from basket. Body: CreateOrderDto (BasketId, DeliveryMethodId, ShippingAddress). Requires auth.

Response: OrderDto.

GET /api/orders

Get all orders for current user. Requires auth.

Response: OrderDto[].

GET /api/orders/{id}

Get specific order by ID (must belong to current user). Requires auth.

Response: OrderDto | 404.

GET /api/orders/deliveryMethods

Get all delivery methods. Requires auth.

Response: DeliveryMethodDto[].

Admin Endpoints [Authorize(Roles = "Admin")]

GET /api/admin/products

Get all products. Admin only.

POST /api/admin/products

Create a new product. Admin only.

PUT /api/admin/products/{id}

Update a product. Admin only.

DELETE /api/admin/products/{id}

Delete a product. Admin only.

GET /api/admin/orders

Get all orders (optional ?email= filter). Admin only.

PUT /api/admin/orders/{id}/status

Update order status. Admin only.

GET /api/admin/users

Get all users. Admin only.

GET /api/admin/users/{id}

Get user by ID. Admin only.

POST /api/admin/users/{id}/roles

Assign role to user. Admin only.

DELETE /api/admin/users/{id}/roles

Remove role from user. Admin only.

POST /api/admin/users/{id}/lockout

Toggle user lockout. Admin only.

DELETE /api/admin/users/{id}

Delete user. Admin only.
